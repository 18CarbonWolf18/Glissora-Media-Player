Recovery key: When you create an account, the app shows a key like A75JR-FLJ32-LU335-8EBHU once. Copy it and keep it somewhere safe, like a password manager or a printed note. It doesn’t show again.

Resetting: Click “Forgot password?” under the sign-in buttons, then enter your username, the recovery key and a new password twice. You’re signed in right away, and your settings, playlists and song list are still there. The old password stops working.

New recovery key: After signing in, the Manage account box has a button for a replacement key. The old key stops working when you make one.

Older accounts: If you already made an account in the previous version, it gets a recovery key the next time you sign in, and the app shows it once.

If you lose both your password and your recovery key, that account’s synced data can’t be recovered. You’d create a new account, and the old file can be deleted from the sync folder by hand.

Features Included so far

1. Custom themes [ Liquid Glass, Frosted Glass and Solid Color ]

2. Playlists [ You can create and add songs to these playlist at your own pace ]

3. Lyrics [ Must import yourself and this is not a feature I would be maintaining ]

4. Audio Settings [ Standard and System App ]

5. Seek Bar [ Classic, Glow, Bold, Thin and Rainbow ] The preview slider 
is a work in progress and at the moment it does nothing.

6. Storage [ Tells what is being used by the music player and what is left on that storage device itself.

7. Account system

8. Custom song covers [ Static and Music Video ]

What does NOT sync [ Songs can not be stored on the account and must be placed in a folder "this helps without creating the playlists on more than one device".

What does sync [ Theme color, glass transparency, simple look, saved presets, seek bar style, cover mode, volume, audio mode, playlists (by song name) and whether the test song is removed. Click Sync now to also sync your song list and lyrics. The audio files themselves can’t be stored in your account, so on a new device your songs appear as “not on this device” until you add the files with Add songs or Add folder. Keeping your music in OneDrive, Google Drive or iCloud makes that quick. ]
